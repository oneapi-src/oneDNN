# Compute-bound coverage for the model fit: long sequences, large head
# sizes and enough batch-heads to fill the machine. Arithmetic intensity
# is q*k/(q+k) flops per byte of Q/K/V/O traffic, 1000 to 8000 here, far
# above the ridge of any part, so these shapes pin down the systolic
# terms (dpas_issue_cycles, dpas_latency_cycles, mma_cycles_per_flop)
# that memory-bound shapes leave free; the fitter keeps the throughput
# floor mma_cycles_per_flop free for that reason. Each problem runs 0.3 to
# 20 ms per call, so a top-k sweep takes about a minute per line.

# Long self-attention, D=128
b=1 h=32 q=4096 k=4096 d=128 dt=f16
b=1 h=32 q=4096 k=4096 d=128 dt=f16 mask=buffer_2d mdt=f16
b=4 h=32 q=2048 k=2048 d=128 dt=f16
b=4 h=32 q=2048 k=2048 d=128 dt=f16 args=--ktag=abdc
b=1 h=32 q=8192 k=8192 d=128 dt=f16 mask=causal_top_left
b=1 h=32 q=8192 k=8192 d=128 dt=f16 mask=causal_top_left args=--ktag=abdc
b=1 h=32 hk=8 q=4096 k=4096 d=128 dt=f16 args=--ktag=abdc

# Large head sizes
b=2 h=16 q=4096 k=4096 d=256 dt=f16
